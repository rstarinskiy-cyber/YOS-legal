# YOS — Legal pages

Public static pages for App Store Connect (Privacy, Support, Terms).

**Do not put product source here.** Sync HTML from the private `YOS` repo `docs/*.html` when legal copy changes.

## App languages covered

Matches `Localizable.xcstrings` locales in the YOS app:

| Locale | Path |
|--------|------|
| English (`en`) | `/` (root) |
| Russian (`ru`) | `/ru/` |
